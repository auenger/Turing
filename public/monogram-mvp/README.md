# 双字母共形实验 MVP

一个完全运行在浏览器中的双字母几何 Logo 生成器。

## 当前范围

- 支持 A 至 Z 中任意两个大写字母。
- 六种组合关系：穿插、熔合、负形、共轴、抱合和斜向咬合。
- 可调整笔画重量、重叠强度和关系张力。
- 构造圆直接取自最终边缘的圆心与半径；直线与相切标记也来自实际边界。
- 使用与 Logo Lab 对齐的 15 秒五阶段时间轴：直边定位、构造圆展开、边缘成形、渐进填黑、完整标志。
- 构造动画自动循环，支持播放暂停、重播、循环、速度、拖动和阶段跳转。
- 可导出透明背景的 SVG 和 1280×800 PNG。

## 边缘构造

`boundary-geometry.js` 用标准圆弧和直线表达封闭区域，通过解析求交、区域合并与切除，保留最终的内外边缘。不是给中心线加粗，也不是用白色笔画盖住交叉点。

S / R 复用 `../logo-geometry.js` 中已确认的 Lab 轮廓；其他字母由圆环、圆腹和多边形实体构建。SVG 仅使用 M / L / A / Z，没有字体描摹或贝塞尔拟合。描边动画与黑色填充使用同一份路径，孔洞在导出时保持透明。

布尔运算保留真实切口；只在切向一致的边缘接点显示相切标记，不把所有交点假称为相切。该版本解决几何边界一致性，尚不包含针对所有字母对的审美评分或自动光学校正。
